# R8 release 0.5.1

- AGP 9.2.1 / R8 9.2.14; minifyReleaseWithR8 і скорочення ресурсів увімкнено.
- assembleRelease та lintRelease: успішно; lint — 0 помилок, 130 попереджень.
- APK: 2,025,386 байтів, SHA-256 `7257e1e3e09b5e797b8135380ea6b2e4f3948f8db5608039672602f4316f45a9`.
- Підпис SHA-256: `9be25fe62f930e2ea998f4cbedc7a63a8164eb8f30820044a906f695dcae4bd6`; збігається з попереднім debug APK.
- Release не має debuggable-прапорця. Для сумісного оновлення використовується попередній debug-ключ.
- На Android API 37 перевірено оновлення без видалення даних: старий JSON з вкладеним графіком і enum-значеннями читається; деталі відкриваються; перейменування зберігається після зупинки та повторного запуску процесу. Збоїв у crash-буфері немає.
- Під час перевірки виявлено й виправлено видалення R8 конструктора WorkDatabase_Impl; додано точкове правило.

Знімки — із тестового емулятора та зі штучними даними, не реальні відключення. Архів mapping відповідає саме наведеному SHA-256 APK.
